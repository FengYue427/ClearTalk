## 中文

大家好，邀请你试用 **ClearTalk**（沟通文本草稿助手）内测版：

**链接**：[https://clear-talk-five.vercel.app](https://clear-talk-five.vercel.app)

**建议体验 3 步**（约 5 分钟）：
1. 把对方发来的一段话粘贴到首页 → 看推荐场景  
2. 选「请假申请」或「快递问题投诉」→ 填表 → 生成  
3. 切换「简短 / 正式」版本，点 👍 或 👎 反馈  

**说明**：生成内容仅供参考，发送前请自行核对。遇到问题截图发群即可。

---

## English

You’re invited to try **ClearTalk** (draft helper for everyday messages):

**Link**: [https://clear-talk-five.vercel.app](https://clear-talk-five.vercel.app)

**Try this** (~5 min):
1. Paste a message you received → see suggested scenarios  
2. Open **Leave Request** or **Package Delivery Issue** → fill the form → Generate  
3. Switch Short / Formal tone; tap 👍 or 👎 for feedback  

Settings → **English** for full EN UI. Generated text is for reference only—please review before sending.
